# h501-gutenberg

A week-4 demo for the **H501** course exploring Project Gutenberg data in a
Jupyter notebook.

## Contents
- `gutenberg.ipynb` — the analysis notebook
- `environment.yml` — conda environment specification

## Setup

```bash
# Create and activate the environment
conda env create -f environment.yml
conda activate <env-name>   # see environment.yml for the name

# Launch Jupyter
jupyter notebook gutenberg.ipynb
```
